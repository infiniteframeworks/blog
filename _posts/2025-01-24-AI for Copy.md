Don't do it.  Just don't do it.  I've done it - it's the way I learn, but it is just. not. good. copy. There is a reason why it has been deemed AI slop.

However, AI for code is very good _as long as you understand and read the code you're executing._ If don't know what the code dues, you are just outsourcing bugs to a future version of yourself.

For writing though, there are ways to use AI _when creating copy_ without having it write for you.

Ask it for strengths and weaknesses of your writing -- I have found it usually has insightful recommendations. 

Use it to brainstorm.  Your mileage may vary, but its output is fodder for _human_ ideas.  

Use it to check grammar.  Passive voice, incorrect tenses, typos -- it is a pretty good proofreader.

Ask it if you are using the right word for a given sentence.
